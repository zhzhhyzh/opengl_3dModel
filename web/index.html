OpenGL Poseidon

A 3D character rendering project featuring Poseidon with dynamic animations, lighting, and interactive controls

Features

  • WASD character movement with walking animations
  • Joint-based animation system (shoulder, elbow, wrist, head)
  • Trident weapon equip, attack, and projectile system
  • Dynamic lighting with 6-direction focus control
  • Multiple texture variations with cycling
  • Orthographic and perspective projection modes
  • Mouse-based camera rotation and zoom
  • Orbiting visual effects
  • Audio effects for actions and ambiance
  • Wireframe rendering mode

Controls

KeyAction
WASDMove character
ZXCWeapon actions (charge, swing, projectile)
1-5Cycle textures
